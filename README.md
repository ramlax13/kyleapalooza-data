# kyleapalooza-data

Public listing data for the Kyle-a-Palooza Park City housing site (June 2027).
`listings.json` is read at runtime by the site, so updates here go live within ~5 minutes without a site deploy.
Contains public rental-listing info only (names, links, photos, prices, bed counts). No votes, voter names, or secrets.
Generated by `build.py`; do not edit by hand.
